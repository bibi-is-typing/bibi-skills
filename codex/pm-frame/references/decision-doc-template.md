# 결정문 양식

6단계 산출물. 1~5단계에서 나온 내용을 옮겨 담는다. 핵심 정보가 비어 있으면 [미정: 확인할 내용]으로 남긴다. 확인 담당·기한도 미정일 수 있다. 작은 결정은 필요한 항목만 쓰되 문제·근거·결정 상태·다음 행동은 보존한다. 공유판에서는 7장을 삭제하고 다른 장·인용·링크에도 기밀이나 개인 역할 메모가 남지 않게 한다.

```markdown
# [주제] 결정문

- 작성: [이름] · [날짜] · v[N]
- 상태: [초안 / 제안 / 확정]
- 결정자: [이름/직책 또는 미정]
- 공개 수위: [내부 / 리더 공유 / 전사]
- 독자: [직접 받는 사람] · 전달될 수 있는 범위: [그 사람이 다시 보낼 수 있는 사람]

## 결정 또는 결정 제안 (한 문단)

[확정: 무엇을 한다 / 제안: 무엇을 제안한다]. [언제까지] [누가] 진행한다. [무엇을] 기준으로 [언제] 다시 판단한다. 미정인 담당·날짜·기준은 확정한 것처럼 쓰지 않는다.

## 1. 문제

- 요청 원문: [받은 요청 그대로]
- 재정의한 문제: [누가 무엇 때문에 무엇을 못 한다. 해법 단어 없이]
- 문제의 주인: [이름/팀]
- 문제 사다리: [요청 → 직접 문제 → 운영 문제 → 상위 문제] (공개 수위 표시)

## 2. 근거

| 주장 | 분류 | 출처 |
|---|---|---|
| | 사실·데이터 / 사실·현장 진술(직접·전언) / 해석 / 추측 | |

**검증할 가정** (위험 큰 순)

| 가정 | 틀리면 | 확인 방법 | 담당 | 기한 |
|---|---|---|---|---|

## 3. 왜 지금

- 지금 해야 하는 이유: [안 하면 무엇이 생기나]
- 지금 할 것:
- 다음으로 미룰 것:
- 하지 않을 것:

## 4. 해결책

| 대안 | 해결되는 것 | 한계 | 비용·되돌림 |
|---|---|---|---|
| 아무것도 안 함 | | | |
| | | | |
| (선택) | | | |

- 선택 이유: [문제의 요소와 짝지어]
- 반증 조건: [이런 신호가 보이면 틀린 것]
- 실패 비용 상한: [최악일 때 잃는 것]

## 5. 성공 기준

| 지표 | 종류 | 기준선 | 목표 | 측정 방법 |
|---|---|---|---|---|
| | 후행 / 선행 / 가드레일 | | | |

**최소 검증**: [무엇을] [어떤 범위로] [언제까지]. 성공 기준 [ ], 중단 기준 [ ].

## 6. 실행과 실험

| 할 일 | 담당 | 기한 |
|---|---|---|

- 재검토 시점: [날짜 또는 조건]
- 열린 결정: [아직 못 정한 것, 결정자, 시점]

## 7. PM 몫 (내부 전용, 공유판에서는 뺀다)

| 구분 | 내용 |
|---|---|
| 한비가 쥐는 일 | [문제 정의, 결정 기록, 측정 설계·보고, 조율 중 이 프로젝트에 해당하는 것] |
| 넘기는 일 | [제작, 콘텐츠, 구현 등, 담당 이름] |
| 기준선 | [무엇을, 언제, 누가 재나] |
| 이력 문장 초안 | [문제] → [조율한 팀] → [출시한 것] → [실제 측정한 지표 변화 또는 측정 예정] |
| 빈칸과 채울 시점 | [아직 없는 숫자·경험, 언제 생기나] |
| 연결되는 역량 | [AI 통합 PM, 측정·GA4, 시스템 통합, 변화 관리 중 해당하는 것] |
| 채우는 빈칸 | [제공된 PM 역할·경험 목록 중 이번 일이 채우는 항목. 자료 없으면 미확인] |
```
